# 📄 Talent Track-Pro – AI-Powered Resume Analyzer  

Talent Track-Pro is an AI-powered tool that helps job seekers optimize their resumes by analyzing them against job descriptions. It provides insights into job match percentage, missing keywords, and resume improvement tips using Google's Gemini AI.  

## 🚀 Features  
- ✅ **Job Match Score** – Check how well your resume aligns with a job description.  
- ✅ **Missing Keywords** – Identify key skills or experiences missing from your resume.  
- ✅ **Resume Improvement Tips** – Get AI-driven recommendations to enhance your resume.  

## 🛠️ Technologies Used  
- **Streamlit** – For an interactive web interface  
- **Google Gemini AI** – For resume analysis  
- **PyPDF2** – To extract text from PDFs  
- **Dotenv** – To securely manage API keys  

## 📌 How It Works  
1. **Enter** the job field/position.  
2. **Paste** the job description.  
3. **Upload** your resume (PDF format).  
4. **Get AI-powered insights** on how to improve your resume!
